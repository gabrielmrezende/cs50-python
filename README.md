This repository contains my solutions and notes from **Harvard University's CS50P: Introduction to Programming with Python**.

The course focuses on fundamental programming concepts using Python, including:

- Variables
- Conditionals
- Loops
- Functions
- Exceptions
- File I/O
- Regular Expressions
- Object-Oriented Programming
- Unit Testing
