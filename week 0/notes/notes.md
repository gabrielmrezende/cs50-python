# CS50P -- Lecture 0: Introduction to Python

## Summary Notes

### 1. What is Python

-   Python is a **high-level programming language**.
-   It has a **simple and readable syntax**.
-   Widely used in **automation, data science, artificial intelligence,
    web development, and scripting**.

### 2. Interpreter

-   Python is an **interpreted language**.
-   Code is executed **line by line** by the Python interpreter.

### 3. First Program

``` python
print("hello, world")
```

-   `print()` is a function used to **display text in the terminal**.

### 4. Strings

-   Text in Python is called a **string**.
-   Strings can use **single quotes** or **double quotes**.

Example:

``` python
print("Hello")
print('Hello')
```

### 5. Variables

-   Variables **store values in memory**.
-   Python does **not require explicit type declarations**.

Example:

``` python
name = "Gabriel"
print(name)
```

### 6. User Input

-   The `input()` function allows programs to **receive data from the
    user**.

Example:

``` python
name = input("What is your name? ")
print("Hello,", name)
```

### 7. Comments

-   Comments explain the code.
-   They are **ignored by the Python interpreter**.

Example:

``` python
# This is a comment
```

### 8. Functions

-   A **function** is a reusable block of code.
-   `print()` and `input()` are examples of **built‑in Python
    functions**.

### 9. Common Errors

-   **SyntaxError** → invalid Python syntax
-   **NameError** → variable not defined
-   **IndentationError** → incorrect indentation

### 10. Good Beginner Practices

-   Write **readable code**.
-   Use **clear variable names**.
-   Comment code when necessary.
